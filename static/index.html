Duplicate protection

One-time GX39 preparation required before the first real upload.

If GX39 creates an object but its HTTP response is lost, the app cannot safely assume that creation failed. Without this field, a retry could create the same object twice.

The tool writes a stable technical value such as CDM:<profile>:<source DataID> to every created object. During a retry it reads this value, finds the existing object and continues instead of creating a duplicate.
